# Swiggy-Marketing-Strategy-Analysis

# 📘 Project Overview
This Power BI project focuses on analyzing **Swiggy’s customer and marketing strategy** to identify key insights that enhance marketing strategies and improve customer retention. This dashboard evaluates **the impact and performance of a marketing campaign**, helping stakeholders understand campaign reach, conversions, and ROI.

# Objectives
- Understand customer purchase behavior and preferences  
- Identify top-performing locations, products, and time periods  
- Evaluate marketing campaign effectiveness  
- Suggest data-driven marketing strategies for Swiggy

# Tools & Techniques Used
- **Power BI** – Data cleaning, modeling, and visualization  
- **Power Query** – Data transformation and preparation  
- **DAX** – Calculations for KPIs and custom metrics
  
# Dashboard Highlights
- Interactive slicers for filtering by date, region, and category  
- Visuals include **bar charts**, **line graphs**, and **donut charts**  
- KPI cards for total orders, average revenue, and customer growth
  
# Key Insights
- Discovered **peak order times** and **top-performing locations**  
- Found strong **repeat customer segments**, showing high loyalty  
- Optimized **marketing ROI** by identifying high-impact promotions
- Helped optimize **budget allocation** across channels
  
# Learnings
Through these Power BI projects, I gained hands-on experience in transforming raw business data into meaningful insights. 
These dashboards demonstrate how **data analytics can drive marketing efficiency and strategic decision-making**.
